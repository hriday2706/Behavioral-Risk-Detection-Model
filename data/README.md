# Synthetic Sessions Dataset

This directory contains synthetic session event and feature data for the SentinelFlow proof of concept.

- `synthetic_sessions.csv`: 1,200 simulated sessions across routine (50%), ambiguous (30%), and elevated-risk (20%) scenario families.
- Features are generated strictly through `src.feature_extraction.extract_session_features`.
- No personal data, real banking credentials, or live network telemetry is contained in this dataset.
